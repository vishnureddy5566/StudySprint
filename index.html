Project details and report guide

PROJECT BRIEF

StudySprint: a student study planner

StudySprint is a responsive, browser-based planner for students managing multiple subjects, assignments, and exam topics. It brings study tasks, deadlines, difficulty, next actions, and focus sessions into one dashboard. Its transparent priority rule helps users choose what to work on first.

Problem and goal

Students may track coursework in several places and find it hard to turn a long list into a manageable next action. StudySprint provides one place to capture a study item, see its urgency, and spend a focused interval working on it. The primary target users are college and university students; independent learners are also suitable users.

Features and scope

  • Add a task with its name, course, optional deadline, perceived difficulty, and next step.
  • Rank active tasks, filter by status, mark them complete or in progress, and delete them.
  • Use a 25-minute focus timer or a 5-minute break timer; pause and reset sessions.
  • Track completed focus minutes and progress toward a 60-minute daily goal.
  • Save tasks and sessions in the browser. Data is not uploaded to a server.

Accounts, cloud sync, notifications, collaboration, calendar integration, syllabus import, and AI-generated advice are outside the current scope. AI assisted development; the running app does not call an AI service.

Priority rule

Tasks are sorted by urgency points plus twice their difficulty score. Difficulty is Light = 1, Moderate = 2, or Challenging = 3. Urgency is 12 for overdue, 10 due today, 8 due tomorrow, 6 due within 3 days, 3 due within 7 days, and 1 due later. A task without a deadline receives only its difficulty points. Higher scores appear first, with older tasks first in a tie. This is an organizational hint, not a prediction of grades or workload.

Tools and implementation

  • HTML5 provides the semantic page structure, controls, and task-entry dialog.
  • CSS3 provides the responsive dashboard and visual states.
  • Vanilla JavaScript implements task management, sorting, filtering, timer behavior, and rendering.
  • Browser LocalStorage stores task and focus-session data under studysprint.v1.
  • Codex AI assistant supported project planning and code drafting. Keep actual prompts and screenshots from your work for the submitted report.

The subject data model contains id, name, course, due, difficulty, notes, completed, and createdAt. A focus-session record contains date, minutes, and completedAt. The app works without a build step or package installation. Google Fonts are optional; system fallbacks are provided.

Report-ready draft

1. Introduction

Students may have several assignments, course topics, and examination deadlines at the same time. When those obligations are written in separate places, it can be difficult to decide what to work on next. StudySprint is a responsive web application that brings a student's study tasks and focus sessions together in one dashboard. A student can record a task, set an optional deadline and difficulty, write a small next action, and see active tasks ordered by a simple priority rule.

The application was developed with AI assistance for planning, interface structure, and implementation support. The developer reviewed and adapted the generated code and used an explicit deadline-and-difficulty formula so task ordering is visible to the user. The running application does not send data to an AI service; task details are stored in the browser on the user's device.

2. Target User

The primary target users are college and university students who manage several subjects and want to keep deadlines, next actions, and focused study time in one place. The interface is designed for an individual user who wants a simple planner rather than a full learning management system. It may also suit independent learners who want a task list and a basic focus timer.

3. Tools Used

HTML5 is used for structure and controls; CSS3 for the responsive layout and visual states; JavaScript for task management, priority ordering, filters, and timer logic; and LocalStorage for browser-local persistence. Codex AI assistant was used to assist with project scoping, interface planning, and code drafting. The application runs in a modern web browser.

5. Application Design and Development

StudySprint uses a single-page dashboard. Its desktop layout has a navigation sidebar and a main area with a summary row, study-priority list, daily-goal indicator, and focus timer. On narrow screens, the sidebar is hidden and the content stacks into one column. An add-task dialog collects task name, category, deadline, difficulty, and next action. JavaScript stores each task as a structured object, sorts active items by the documented score, and re-renders the interface after changes. Completed focus sessions update the total and daily goal. The browser's LocalStorage API preserves the data on the current browser and device.

6. Final Application

The application supports task entry, optional deadlines, difficulty labels, priority ordering, next-step notes, list filters, completion and deletion actions, a focus timer with a short-break mode, a daily focus-goal indicator, and browser-local storage. The student can open this HTML file in a modern browser without creating an account. Add a public deployment URL only if you publish the application; otherwise describe it as a local browser application.

7. Conclusion

StudySprint organizes study tasks and focused work sessions in a single lightweight interface. Its priority score helps users notice urgent or challenging work, while the next-step field encourages turning a large subject into an actionable task. AI assistance supported the development workflow, while the final app's behavior remains transparent and browser-local. Future improvements could include editable weights, calendar export, data backup/import, reminders, user research, and an optional AI study-planning service with clear consent and privacy controls.

Manual demonstration checklist

Run and record these checks yourself before reporting their results: add tasks with different deadlines and difficulties; confirm their order; use each filter; mark items complete and in progress; delete an item; start, pause, resume, and reset both timer modes; complete a focus session and inspect the daily total; reload the page to check persistence; and try the layout at phone width and navigate the form by keyboard.

Limitations and future work

Data belongs to the current browser profile and device; clearing browser storage removes it. The timer needs the page to remain open and does not notify after the tab closes. Difficulty is self-reported and the formula does not estimate task duration, prerequisites, or available study hours. No user-study results are included; report such results only if you conduct the study.
